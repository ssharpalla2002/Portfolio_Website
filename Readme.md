# Portfolio Website

A personal portfolio website built with React.js and Vite to showcase my profile. It features a clean design, smooth animations that highlight my projects, and a functional contact form for easy connection.

## Features

- Modular React components for each section of the portfolio  
- Smooth animations and transitions using Framer Motion  
- Clean and modern user interface  
- Dynamic backgrounds and hover effects  
- Functional contact form using EmailJS  
- Fast and reliable deployment with Vercel  

---

## Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/ssharpalla2002/Portfolio_Website.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open the application in your browser:
   ```
   http://localhost:5173
   ```
